# Стартовий промпт

Відкрий нову сесію Claude Code **у цій папці** (`<репозиторій>\phone`) —
тоді `CLAUDE.md` з повною процедурою підвантажиться сам. Встав текст нижче, підставивши своє.

Перед цим на телефоні: Налаштування → Про телефон → 7 разів тапнути по номеру збірки (на Xiaomi —
«Версія MIUI/ОС») → Параметри розробника → увімкнути «Налагодження USB» і «Бездротове налагодження».
Телефон і ПК мають бути в одній Wi-Fi мережі.

---

Зроби дебловт Android-телефона за процедурою з CLAUDE.md, повністю, по кроках.

- IP телефона: <IP>
- Чий телефон: <мій / дитячий з Family Link / батьків / ...>
- Що для мене важливо: <батарея / швидкість / реклама / приватність>
- Чим точно користуються: <необов'язково, інакше спитай чеклістом>

Спершу крок 0: онови базу UAD, якщо застаріла, і пошукай свіжі списки під цей бренд і оболонку.
Перед будь-якими змінами зроби бекап, покажи звіт і спитай мене. Наприкінці онови KNOWLEDGE.md
і SOURCES.md тим, що дізнався.
