# Regular (unsupervised) phone. Apps and Google features the owner uses were kept by their choice
# (social apps, browsers, Android System Intelligence, Android Auto, Pixel accessories, …).
#
# Apply:  PHONE=<ip:port> bash scripts/disable.sh devices/google-pixel3-blueline/debloat.txt [1]
# Undo:   PHONE=<ip:port> bash scripts/restore.sh devices/google-pixel3-blueline/debloat.txt
# Disabled for user 0 only (pm disable-user), never uninstalled. Wait ~30 s after the last pm call
# before rebooting, or the state may not reach disk.

#
