# Guide for AI assistants other than Claude Code

The full procedure is [`CLAUDE.md`](CLAUDE.md) in this folder. Claude Code reads it automatically; any
other assistant (Codex, Cursor, Gemini, Copilot, …) must read it first and follow it exactly, together with
the files it points to (`KNOWLEDGE.md`, `SOURCES.md`, `devices/`). The user starts with the text from
`PROMPT.md`. Answer in Ukrainian.
