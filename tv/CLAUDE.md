# Деблот Android TV / Google TV — робочі інструкції

Ця папка — «пам'ять» для деблоту телевізорів і приставок. Кожна нова сесія для нового (або вже
знайомого) пристрою починається тут. Користувач спілкується українською — відповідай українською.

Основа — репозиторій **CleanYourTV**: https://github.com/Gathin23/cleanyourtv
Локальна копія лежить **поруч із цим репозиторієм**: `<CYT>` = `..\..\cleanyourtv` від цієї папки
(venv з `adb-shell` — `<CYT>\tools\venv`; якщо його нема — створи з `tools\requirements.txt`).
Записи для відкату CleanYourTV: `~\.cleanyourtv\` (`%USERPROFILE%\.cleanyourtv`).
Його `PROMPT.md` — базовий порядок дій; цей файл його доповнює і МАЄ ПЕРЕВАГУ, де вони розходяться.

Перед роботою прочитай: `..\LOCAL.md` (якщо є — приватні деталі цього ПК: шляхи, IP пристроїв,
власники; у git його немає), `devices/README.md` (відомі пристрої), `lessons.md` (граблі, на які вже
наступали), `SOURCES.md` (де шукати), і для знайомого пристрою — його `devices/<назва>/notes.md`.
Користувач стартує сесію текстом із `PROMPT.md`.
Репозиторій публічний: IP, назви Wi‑Fi, імена, абсолютні шляхи й інші приватні деталі пиши лише в
`..\LOCAL.md`, а в `devices/`, `lessons.md` тощо — узагальнено.

## Порядок роботи з пристроєм

1. **Оновити базу.** `git -C <CYT> pull` (у копії можуть бути локальні
   незакомічені зміни лаунчера і списки — pull їх не чіпає; якщо конфлікт — зупинись і спитай).
   Глянь `CHANGELOG`/нові `examples/`, що змінилось з минулого разу.
2. **Підключитись і впізнати.** `TV_HOST=<ip>`; `tools\tv.py --probe` (модель, device-codename,
   Android, прошивка). Попередь користувача про запит «Дозволити налагодження» на екрані.
   Додатково: `getprop ro.board.platform`, `ro.config.low_ram`, `wm size`, `df -h /data`,
   хто HOME (`cmd package resolve-activity ... HOME`), пульт (`getevent -i | grep name`, Bluetooth чи IR).
3. **Знайти відповідник у репо.** Шукай у `cleanyourtv/examples/*/debloat.txt` за моделлю, кодовою
   назвою плати (`ro.product.device`), брендом-виробником (Changhong/Homwee, TCL, MStar/MediaTek,
   Amlogic), версією прошивки. Підходить навіть інший бренд на тій самій платі (ERGO = RCA AI PONT).
   Перевір і `devices/` тут. Якщо нічого — **дослідження** (див. нижче).
4. **Базовий замір ДО змін** (див. «Як міряти»). Збережи повний список пакетів у
   `~\.cleanyourtv\<пристрій>-packages-all.txt`.
5. **Аналіз і пропозиція.** Що запущено (`dumpsys meminfo`, `dumpsys procstats --hours 3`), хто
   стартує при завантаженні (`logcat -d | grep "Start proc"`), що з цього телеметрія/реклама/ACR/
   промо/оновлювачі/передвстановлене. Для кожного кандидата: прапорці (`dumpsys package <p> | grep
   pkgFlags` — PERSISTENT не чіпати), чи є в інших списках репо, що зламається. Покажи користувачу
   таблицю «що / скільки RAM / що втратиш» + окремо «на твій вибір» (голос, Chromecast, пульт з
   телефона, оновлення прошивки, стрімінги) + «свідомо не чіпаю». **Нічого не вимикай без «так».**
6. **Застосування.** Список кладеш у `devices/<пристрій>/debloat*.txt` (з шапкою: модель, прошивка,
   що збережено і чому, команда відкату) і запускаєш `cleanyourtv\tools\disable.ps1 -TvHost <ip>
   <шлях до списку>`. Скрипт сам пише запис для відкату. Кожен наступний раунд — ОКРЕМИЙ файл.
7. **Перевірка після перезавантаження.** Повторний замір у тих самих умовах; перевір, що нічого не
   ввімкнулось назад (`pm list packages -d`), HOME, пульт (попроси натиснути реальні кнопки),
   входи HDMI, скріншот головного екрана — надішли користувачу.
8. **Звіт.** Таблиця до/після, що вимкнено, що збережено, як відкотити, що не перевірено.
   Онови `devices/<пристрій>/notes.md` і `devices/README.md`. Нагадай вимкнути налагодження USB.

## Як міряти (щоб цифри були чесні)

- Головна метрика: `MemAvailable` з `/proc/meminfo` + використаний swap (`SwapTotal-SwapFree`) +
  PSS топ-процесів (`dumpsys meminfo`). Лаунчер окремо: `dumpsys meminfo <пакет> | grep TOTAL`.
- Порівнюй лише **однаковий час після завантаження** (uptime з `/proc/uptime`): зроби «до» через
  N хв після старту, «після» — перезавантаж і зачекай ті самі N хв. Скрипт: `tools\measure.ps1`.
- Кажи прямо, де оцінка, а де замір; якщо «до» не було свіжим після ребута — попередь, що частина
  приросту — ефект свіжого старту.
- ~400 «процесів» у `ps -A` — це здебільшого потоки ядра; рахуй Android-застосунки окремо.

## Правила, яких не порушувати

- Тільки `pm disable-user --user 0`. `pm uninstall --user 0` — лише для того, що прошивка сама
  вмикає назад (так було з FAST-каналами `com.cltv.fast`), і лише з дозволу; повернення —
  `cmd package install-existing <пакет>`. Видаляти сторонні застосунки користувача — лише на прохання.
- Не чіпати: Live TV/тюнер (через нього HDMI), сервіси входів, пульт і Bluetooth (якщо пульт BT),
  клавіатуру, Play Store / Play Services, заводське меню, PERSISTENT-пакети, те, що в шапці
  відповідного `examples/` позначено KEEP.
- **Майстер налаштування `setupwraith`:** перед вимкненням — `dumpsys wifi | grep cname=`. Якщо
  йому належить мережа, якою ТВ зараз підключений, — НЕ вимикати (ТВ відвалиться від Wi-Fi).
  Якщо лише стара/гостьова — можна з `FORCE_SETUPWRAITH=1`, попередивши, що та мережа зітреться.
- Якщо користувач сказав «лаунчер не міняємо» — не ставити наш лаунчер і не вимикати стоковий.
- Не лізти в заводське/сервісне/готельне меню.
- Ніяких комітів/пушів у git без прямої вказівки (глобальне правило користувача).

## Дослідження (нова модель або щоб перевірити, чи нема кращого)

Делегуй субагенту веб-пошук, сам тим часом працюй з пристроєм. Шукати:
- Нові/оновлені списки в CleanYourTV (`examples/`, PR, issues — там часто є свіжі моделі).
- Інші деблот-проєкти й списки для бренду/плати: GitHub (`<brand> android tv debloat`,
  `<package name>`), XDA, 4pda, Reddit r/AndroidTV, Universal Android Debloater (UAD-ng) списки.
- Призначення незнайомих пакетів: шукай точну назву пакета в лапках.
- Відомі проблеми прошивки (автостарт Live TV, повторне ввімкнення пакетів, ACR).
Знахідки, що підтвердились на пристрої, запиши в `lessons.md` / `notes.md` пристрою, нові
корисні джерела — у `SOURCES.md`. Для опису незнайомих пакетів глянь і базу UAD-ng з
`..\phone\uad\uad_lists.json` (якщо нема — `bash ../phone/scripts/update-uad.sh`).

## Корисне

- `tools\ui.ps1 -TvHost <ip> -Keys '...'` — натиснути кнопки й прочитати екран ТЕКСТОМ
  (uiautomator). Працює там, де скріншот порожній (Live TV, захищені вікна), і для навігації
  меню Налаштувань / Play Store без скріншотів. `start:<pkg>/<activity>` запускає екран.
- `tools\channels.ps1` — вимкнення каналів (рядів) на стоковому головному екрані Android TV 9.
- `tools\measure.ps1 -TvHost <ip> -Uptime <сек>` — перезавантаження, очікування, замір.
- Скріншот: `screencap -p /sdcard/s.png` → `tv.py --pull` → прочитати → `rm`.
- Лаунчер CleanYourTV: див. `lessons.md` (тема замість перезбирання, BootHomeService).
