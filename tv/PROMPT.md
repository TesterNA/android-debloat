# Стартовий промпт

Відкрий нову сесію Claude Code **у цій папці** (`<репозиторій>\tv`) —
тоді `CLAUDE.md` з повною процедурою підвантажиться сам. Встав текст нижче, підставивши своє.

Перед цим на ТВ/приставці: Налаштування → Параметри пристрою → Про пристрій → 7 разів OK на
«Збірка» → назад → Параметри розробника → увімкнути «Налагодження USB» (і «Налагодження по мережі»,
якщо такий пункт є). IP — у Налаштування → Мережа. ТВ і ПК мають бути в одній мережі.
Коли на екрані з'явиться «Дозволити налагодження?» — галочка «Завжди» і OK.

---

Зроби дебловт Android TV за процедурою з CLAUDE.md, повністю, по кроках.

- IP: <IP>
- Що це: <ТВ / приставка; модель, якщо знаю — інакше визнач сам>
- Лаунчер: <міняємо на CleanYourTV / НЕ МІНЯЄМО, лише налаштування стокового>
- Що для мене важливо: <швидкість / реклама / приватність / все>
- Чим точно користуються: <застосунки, голосовий пошук, Chromecast, пульт з телефона — необов'язково, інакше спитай чеклістом>

Спершу онови CleanYourTV (`git pull`) і знайди відповідник у `examples/` і `devices/`; якщо нема —
досліди в інтернеті. Перед будь-якими змінами заміряй пам'ять, покажи звіт і спитай мене.
Наприкінці заміряй після перезавантаження в тих самих умовах і онови `lessons.md`,
`devices/` і `SOURCES.md` тим, що дізнався.

---

Для вже відомого пристрою (див. `devices/README.md`) достатньо:

> Повернись до <ERGO / Xiaomi MOOR2 / Mi Box S> (IP <IP>) за CLAUDE.md. Хочу: <що зробити>.

## Що де лежить
- `CLAUDE.md` — процедура і правила для Claude.
- `lessons.md` — що з'ясували на практиці (граблі, обходи, цифри).
- `SOURCES.md` — репозиторії й списки, на які спираємось.
- `devices/` — по папці на пристрій: нотатки, копії списків, тема лаунчера.
- `tools/` — `ui.ps1` (читати екран текстом і тиснути кнопки), `channels.ps1` (вимикати ряди на
  стоковому головному екрані), `measure.ps1` (чесний замір пам'яті після ребута).
- `patches/` — наша доробка лаунчера (BootHomeService) і конфіг Xiaomi; `git apply` на свіжий CleanYourTV.

**Не видаляй** локальну копію CleanYourTV (поруч із репозиторієм) і `~\.cleanyourtv` — там
оригінальні списки і записи для відкату. Наприкінці вимикай «Налагодження USB» (на Mi Box без
цього не працює USB-порт).
